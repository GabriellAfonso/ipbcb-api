### Member (changed)

| Field | Type | Notes |
|---|---|---|
| `photo` | `ImageField(upload_to="members/", null=True, blank=True)` | **New.** Stored name `members/<uuid4 hex>.<ext>`, ext from decoded format. Written through `MemberPhotoStorage`, never `FieldFile.save` (research R-06) |

All other fields unchanged (see `specs/members/spec.md`).

### MemberChangeLog (new, `features/members/models/member_change_log.py`)

| Field | Type | Notes |
|---|---|---|
| `id` | `BigAutoField` | |
| `member` | `ForeignKey(Member, on_delete=CASCADE, related_name="change_log")` | History goes with the member (FR-026) |
| `editor` | `ForeignKey(settings.AUTH_USER_MODEL, on_delete=SET_NULL, null=True, related_name="+")` | Survives account deletion; `related_name="+"` so `accounts.User` gains no reverse accessor into members |
| `field` | `CharField(max_length=32)` | Member field name, `created` or `photo` |
| `old_value` | `TextField(null=True)` | Rendered text (R-02) |
| `new_value` | `TextField(null=True)` | Rendered text; photo markers `photo changed` / `photo removed` |
| `changed_at` | `DateTimeField(auto_now_add=True)` | |

`Meta`: `ordering = ["-changed_at", "-id"]`, `verbose_name = "member change log entry"`,
`verbose_name_plural = "member change log"`. `__str__`: `f"{member_id}.{field} at {changed_at}"`
(no member data).

Migration: one, generated by `makemigrations` (AddField `photo`, CreateModel
`MemberChangeLog`). Additive; rollback = migrate to `0002`.

History field keys: `created`, `photo`, `name`, `first_name`, `last_name`, `birth_date`,
`gender`, `status`, `role`, `ministries`, `baptism_date`, `is_active`.

absolute `photo_url` with `request.build_absolute_uri`, like `ProfileSerializer`.

## Validation rules

| Rule | Where | Error |
|---|---|---|
| Body is a JSON object | view, `require_object_body` | 400 `VALIDATION_ERROR` |
| `name` required on create, non-blank, ≤ 255; `first_name`/`last_name` ≤ 255 | serializer | 400 `VALIDATION_ERROR` with `field_errors` |
| `gender` ∈ {`M`, `F`} or null | serializer | 400 |
| `status_id`, `role_id` int or null; `ministry_ids` list of int | serializer | 400 |
| Unexpected field (e.g. `photo`, `created_at`, `id`) | serializer rejects unknown keys | 400 |
| Status / role id exists | service via repository | 400, message names the id |
| Every ministry id exists | service via repository | 400, message lists missing ids |
| `birth_date`, `baptism_date` ≤ today (injected `Clock`) | domain rule | 400, message has the date |
| `baptism_date` ≥ `birth_date`, on the merged record | domain rule | 400, message has both dates |
| Photo: decodable JPEG/PNG/WEBP/GIF, ≤ 10 MB | `core.files.image_validation` | 400 |
| Photo field missing in multipart | view | 400 |

## State transitions

None beyond create → (edit)* → delete. `is_active` toggles freely; it is data, not a state
machine. Photo: none ↔ present, replace keeps "present".
